# shokat bitopic scripts
Plotting data for bitopic inhibitor project

This is a working repo and sandbox for Jack Stevenson's work on a Shokat bitopic inhibitor project. It was originally used to develop what would become jackwalkerstevenson/doseplotr and still depends heavily on doseplotr. It supports the manuscript "A design approach for bitopic kinase inhibitors".

Written by Jack Stevenson, Shokat lab, UCSF in 2022–26.
